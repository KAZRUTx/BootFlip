# BootFlip
BootFlip lets you jump from Windows to Linux (and back) with a single click, instead of mashing a boot-menu key at startup. It sets a one-time UEFI boot target and restarts, or hibernates the current system first so you can resume it later.

Why? Switching in a dual-boot setup normally means a full shutdown, a keypress at the right moment, and losing all open work. BootFlip makes it one button, and the optional hibernation keeps your session alive.
